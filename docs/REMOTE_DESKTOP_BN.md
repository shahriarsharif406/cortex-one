# রিমোট ডেস্কটপ (RustDesk) সেটআপ: নিজের কম্পিউটারের পর্দা ফোনে দেখা ও চালানো

Cortex One নিজে রিমোট ডেস্কটপ **বানায় না**। পর্দা দেখানো ও টাচ/মাউস নেওয়ার কাজ করে **RustDesk** (আলাদা ফ্রি অ্যাপ)। Cortex One শুধু তিনটি ছোট কাজ করে:

1. `remote_desktop_status`: RustDesk কম্পিউটারে চলছে কিনা (এবং সম্ভব হলে সংস্করণ) বলে। শুধু প্রোগ্রামের নাম দেখে, কোনো ফাইল বা পাসওয়ার্ড পড়ে না।
2. `remote_desktop_start`: RustDesk চালু করে। এটা **ঝুঁকিপূর্ণ কাজ**: ফোনে ধাপে ধাপে নিশ্চিত করতে হয় (পর্দায় কী হবে দেখায়, তারপর ফোনের আঙুলের ছাপ/পিন)। AI শুধু অনুরোধ করতে পারে, নিজে চালাতে পারে না।
3. অ্যাপে "RustDesk খুলুন" বোতাম: ফোনের RustDesk অ্যাপ আপনার দেওয়া ID সহ খোলে।

> এটা আপনার **নিজের কম্পিউটার** চালানোর জন্য। অন্যের কম্পিউটারে অনুমতি ছাড়া ঢোকা অপরাধ, আর RustDesk-এর নিজস্ব শর্তাবলিও নিজের/অনুমোদিত ডিভাইসের জন্য। এই গাইড সেই ভরসায় লেখা।

## ১. দুই দিকেই ইনস্টল

- **কম্পিউটারে (ল্যাপটপ ও ডেস্কটপ):** https://rustdesk.com থেকে Windows ইনস্টলার নামান, ইনস্টল করুন। "Install" দিন (শুধু চালানো নয়), যাতে সার্ভিস হিসেবে চলে এবং লগইনের আগেও/লক স্ক্রিনেও কাজ করে।
- **ফোনে:** Play Store থেকে "RustDesk" ইনস্টল করুন।

## ২. সরাসরি IP দিয়ে যোগাযোগ (Tailscale ঠিকানায়, পাবলিক রিলে ছাড়া)

ডিফল্টে RustDesk তাদের রিলে/রেন্ডেভু সার্ভার ব্যবহার করে। আমরা চাই সরাসরি আপনার Tailscale ঠিকানায়, তাই:

১. কম্পিউটারে RustDesk খুলুন → Settings → **Security** → "Enable direct IP access" (সরাসরি IP অ্যাক্সেস) চালু করুন। পোর্ট সাধারণত 21118।
২. কম্পিউটারের Tailscale IP জানুন (যেমন `100.101.102.103`; Tailscale অ্যাপে দেখা যায়)।
৩. ফোনে RustDesk-এ ওই IP (`100.101.102.103`) লিখে সংযোগ দিন। ফোন ও কম্পিউটার দুটোতেই Tailscale চালু থাকতে হবে।
৪. Settings → Network-এ আপনার নিজস্ব রিলে সার্ভার না থাকলে "ID/Relay server" ফাঁকা রাখুন; সরাসরি IP-তে সংযোগ হলে ডেটা Tailscale (WireGuard) সুড়ঙ্গ দিয়ে এনক্রিপ্টেড যায়।

> সীমা: কখনো কখনো Tailscale সরাসরি পথ না পেয়ে নিজস্ব রিলে (DERP) দিয়ে যায়; তখন ধীর হয়, কিন্তু এনক্রিপ্টেডই থাকে।

## ৩. শক্ত পাসওয়ার্ড ও 2FA (খুব জরুরি)

RustDesk চালু থাকা মানে পাসওয়ার্ড জানা যে কেউ (আপনার Tailscale নেটওয়ার্কের ভেতরে) ঢুকতে পারবে। তাই:

- Settings → Security → **Permanent password** (স্থায়ী পাসওয়ার্ড): লম্বা, একেবারে আলাদা (অন্য কোথাও ব্যবহার করবেন না)। পাসওয়ার্ড ম্যানেজারে রাখুন।
- **Two-factor authentication (2FA)** চালু করুন (Settings → Security → 2FA), অথেনটিকেটর অ্যাপ দিয়ে।
- "One-time password"/অস্থায়ী পাসওয়ার্ড বন্ধ করুন, যদি দরকার না থাকে।
- "Accept connections" বা অ্যাক্সেস কন্ট্রোলে "Full access"-এর বদলে দরকার হলে "View only" বেছে নিতে পারেন।
- **Cortex One কখনো RustDesk-এর পাসওয়ার্ড বা কনফিগ ফাইল পড়ে না, রাখে না।** শুধু আপনার দেওয়া **ID** (সংখ্যা, পাসওয়ার্ড নয়) ফোনে সংরক্ষিত থাকে।

## ৪. Cortex One-এর সাথে জোড়া লাগানো

কম্পিউটারের `config.json`-এ (পাথ নিজের মতো মিলিয়ে):

```json
"allowed_apps": {
  "rustdesk": ["C:\\Program Files\\RustDesk\\rustdesk.exe"]
},
"remote_desktop_app": "rustdesk",
"remote_desktop_process": "rustdesk"
```

তারপর `python -m agent.main doctor` চালান: "রিমোট ডেস্কটপ অ্যাপ allowed_apps-এ আছে" দেখা যাওয়া উচিত।

ফোনের অ্যাপে: কম্পিউটার তালিকা → সেই কম্পিউটারের ✏️ বোতাম → **RustDesk ID** ঘরে ID লিখুন (পাসওয়ার্ড নয়)। হোম পর্দায় "কোডিং সেশন ও রিমোট ডেস্কটপ" কার্ডে:

- **কম্পিউটারে চলছে কিনা**: স্ট্যাটাস দেখায়।
- **কম্পিউটারে RustDesk চালু করুন**: ঝুঁকিপূর্ণ কাজের নিয়মে নিশ্চিত করতে হয়।
- **RustDesk খুলুন**: ফোনে RustDesk অ্যাপ খোলে (`rustdesk://connect/<ID>` লিংকে)।

## ৫. SIM ডেটা সম্পর্কে সতর্কতা

রিমোট ডেস্কটপ ছবি/ভিডিওর মতো ডেটা পাঠায়: কয়েক মিনিটেই অনেক MB খরচ হতে পারে। মোবাইল ডেটায় থাকলে:

- RustDesk-এর ভেতরে ছবির মান "Low/Balanced" এবং কম রেজোলিউশন বেছে নিন।
- দরকার শেষ হলে সংযোগ কেটে দিন।
- Cortex One-এর "ডেটা-সেভার" শুধু নিজের স্ক্রিনশটে কাজ করে, RustDesk-এ নয়।

## ৬. যা পরীক্ষা করা হয়নি

- আসল ফোনে RustDesk-এর `rustdesk://` লিংক ঠিকমতো খোলে কিনা (ভার্সনভেদে আলাদা হতে পারে; না খুললে RustDesk অ্যাপ হাতে খুলে ID বসান)।
- আপনার RustDesk সংস্করণের সেটিং-মেনুর নাম এই গাইডের নামের সাথে হুবহু মিলবে না-ও পারে।
- আসল কম্পিউটারে `remote_desktop_start` (RustDesk চালু করা) ও সংস্করণ বের করা।

## ৭. সমস্যা হলে

| সমস্যা | কী দেখবেন |
|---|---|
| "RustDesk খোলা যায়নি" | ফোনে অ্যাপ ইনস্টল আছে কিনা; হাতে খুলে ID বসান |
| সংযোগ হয় না | দুই দিকেই Tailscale চালু? কম্পিউটারে RustDesk চলছে (`rd_status`)? "Direct IP access" চালু? |
| ধীর/ঝাপসা | মান কমান, Wi-Fi ব্যবহার করুন |
| ল্যাপটপ ঘুমে/বন্ধ | RustDesk কাজ করবে না: আগে জাগান (পাওয়ার কার্ডের "জাগান") |
